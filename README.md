# PenxAgent

Локальная многопользовательская платформа -агентов.

## Components

- backend: Java 21 + Spring Boot
- agent-runtime: AI agent execution
- desktop: Tauri + React + TypeScript
- infrastructure: Docker Compose
- docs: Project documentation

## AI Server

- GPU: NVIDIA RTX 3060 Ti 8 GB
- AI Engine: Ollama
- Database: PostgreSQL
- Network: Tailscale
